L’IA comprend votre bug, jamais vos secrets

FloutIA remplace uniquement les valeurs sensibles : les noms de variables (DATABASE_URL=, API_KEY=), les guillemets, les numéros de version (1.2.3.4) et les URLs de documentation publiques restent intacts pour que l’IA puisse diagnostiquer votre problème avec précision.

Secrets & formats techniques neutralisés

  • Clés API & Cloud : préfixes OpenAI (sk-...), GitHub (ghp_..., github_pat_...), AWS (AKIA..., ASIA...), Slack, Google (AIza...).
  • Authentification & Chaînes : jetons JWT, en-têtes Bearer et Basic, URI postgres://, mongodb://, mysql://, redis://, clés privées PEM / OpenSSH.
  • Variables .env / Configs : détecte PASSWORD, SECRET, TOKEN, API_KEY, CREDENTIAL, même avec des caractères spéciaux (#, ,) dans les valeurs non quotées.
  • Réseau & Système : IPv4 (hors numéros de version), IPv6 (sans faux positifs sur Foo::bad), URLs internes (.local, localhost, 192.168...) et chemins /Users/, /home/, C:\Users\.

Questions fréquentes des développeurs

Pourquoi utiliser FloutIA plutôt qu’envoyer directement en mode « chat temporaire » ?

Un chat temporaire envoie tout de même vos clés API sur Internet vers des serveurs tiers. Avec FloutIA, les secrets ne quittent jamais votre navigateur (CSP connect-src 'none') et le correctif renvoyé par l’IA est réinjecté localement en 1 clic.

Les URLs de documentation ou les mots-clés SQL sont-ils modifiés ?

Non. Les URLs publiques (sans jeton ni identifiant) et les mots comme POSTGRES ou ABSOLUTE restent en clair pour ne pas dégrader la réponse de l’IA.
